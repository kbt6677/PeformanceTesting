# PerformanceTesting

性能テスト（パフォーマンステスト）の計画・設計・実行・分析・報告までを管理するリポジトリです。

## フォルダ構成

| フォルダ | 用途 |
| --- | --- |
| `01_計画/` | 性能テスト計画書（Excel）、テンプレート。**ここに計画書を配置します。** |
| `02_設計/` | テストシナリオ設計、テストデータ設計 |
| `03_スクリプト/` | 負荷ツールのスクリプト（JMeter / Gatling / k6 など） |
| `04_環境構成/` | テスト環境の構成情報、サーバー設定、構成図 |
| `05_実行結果/` | 実行時のログ・メトリクス（生データ） |
| `06_分析レポート/` | 結果分析、ボトルネック調査、報告書 |
| `07_議事録/` | 打ち合わせメモ、意思決定の記録 |
| `docs/` | 補足ドキュメント、用語集、参考資料 |

## 進め方（標準フロー）

```
① 計画  →  ② 設計  →  ③ 準備  →  ④ 実行  →  ⑤ 分析  →  ⑥ 報告
(01)       (02/03)    (04)        (05)        (06)        (06/07)
```

1. **計画 (01)** — 目的・対象・目標性能（SLA/SLO）・スケジュール・体制を `01_計画/性能テスト計画書.xlsx` にまとめる
2. **設計 (02)** — 負荷シナリオ、負荷モデル（同時ユーザー数・スループット）、テストデータを設計する
3. **準備 (03/04)** — スクリプト作成、テスト環境構築
4. **実行 (05)** — テストを実施し、ログ・メトリクスを記録する
5. **分析 (06)** — 結果を分析し、目標達成可否・ボトルネックを評価する
6. **報告 (06/07)** — 報告書をまとめ、関係者に共有する

## 計画書の置き場所

性能テスト計画書（Excel）は次のパスに配置してください。

```
01_計画/性能テスト計画書.xlsx
```
