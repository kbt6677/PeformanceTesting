# 01_計画

性能テストの計画に関する成果物を格納します。

## 配置するもの

- `性能テスト計画書.xlsx` … 本フォルダ直下に配置してください（メインの成果物）
- `テンプレート/` … 計画書のひな形・記入例

## 性能テスト計画書に含めたい項目（チェックリスト）

- [ ] 目的・背景（なぜ性能テストを行うか）
- [ ] テスト対象（システム/機能/API の範囲、対象外の明記）
- [ ] 目標性能（SLA / SLO）
  - [ ] 応答時間（平均 / 95%ile / 99%ile）
  - [ ] スループット（req/s, TPS）
  - [ ] 同時接続/同時ユーザー数
  - [ ] エラー率の許容値
  - [ ] リソース使用率の上限（CPU / メモリ / ディスク / ネットワーク）
- [ ] テストの種類（負荷 / ストレス / スパイク / 耐久 / スケーラビリティ）
- [ ] 負荷モデル（ユーザー数の推移、ramp-up、ピーク、継続時間）
- [ ] テスト環境（本番相当か、差分の明記）
- [ ] テストデータの条件（件数・分布）
- [ ] 使用ツール
- [ ] 測定項目・監視対象
- [ ] スケジュール・体制・役割分担
- [ ] 合否判定基準
- [ ] リスクと前提条件
